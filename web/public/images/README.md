## Generation notes

- All four images were generated by Gemini from prompts derived from the design
  system (`docs/04-design/00-design-foundations.md`). They are PNG rasters.
- **Seed fallback:** the hero photo is also used as the placeholder listing image
  in `supabase/seed.sql` (demo only). Listing cards render a "No photo" fallback
  if the URL is missing.

## Guidelines when editing

- Keep every asset on the blue family; reuse the primitives in `_tools/generate.js`
  instead of hand-writing ad hoc scenes (drift kills the effect).
- Do not renumber or restructure this folder without updating the tracker-referenced
  strategy doc (`docs/04-design/08-image-asset-strategy.md`).

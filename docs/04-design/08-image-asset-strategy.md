# 1. Purpose

This document defines how images and illustrations are used across the marketplace, and which assets must be produced to reach the bar of "a funded startup" rather than "a generic hackathon".

The guiding principle: **every image has a purpose.** One coherent illustration language, applied consistently, reads as polish. A scattered collection of icons and stock photos — however many there are — reads as unpolished, no matter how good each individual asset is.

# 2. Illustration languages (the style system)

Choose one set of languages and do not mix. Use the design-token blue family (`#2563EB` + neutral navy) so every asset stays on-brand.

| Language | Used for |
|---|---|
| **Lifestyle photography** (realistic) | Heroes, trust sections, category banners |
| **Minimal vector / isometric illustrations** | Onboarding, empty states, AI features, system feedback |
| **Clean SaaS UI visuals** (subtle gradients, whitespace) | Dashboard graphics, backgrounds, marketing |

These three map directly to the Oddboard / Notion / Linear / Vercel / Stripe feel while remaining warm and approachable for the Ethiopian market.

# 3. The signature asset (do first)

The single highest-leverage image. A premium isometric illustration of a modern Ethiopian neighborhood where people buy and sell second-hand goods — homes, apartments, electronics, furniture, vehicles, and fashion connected through elegant marketplace cards, with subtle blue connection lines linking buyers and sellers, plus trust badges, AI sparkle icons, and verification shields. Clean, modern, slightly isometric, soft gradients, warm lighting.

This becomes VinTech's visual identity — the first thing a judge sees and remembers.

# 4. Tiered asset plan

**Tier 1 — must-have (build first).** The core that makes the product feel finished while a demo user actually uses the app:

- The signature VinTech neighborhood hero
- Onboarding set (3): Create Account → List Your Item → Receive Offers
- Empty states: No Search Results, No Favorites, No Listings, No Offers
- Error set: 404, 500, Offline
- AI before/after illustration (the differentiator): a raw product photo transforming into a polished marketplace listing

**Tier 2 — high value (build after Tier 1, only if green).**
- Hero photos: Modern Ethiopian Apartment, Seller Taking Photos, Buyer Meeting Seller (reuse across trust sections).
- Trust illustrations: Verified Seller, Safe Transactions, Community Marketplace.

**Tier 3 — garnish (only if time remains; cut freely).**
- Application before/after covers (6 categories)
- Micro-icons (Verified, Sold, Featured, Negotiable, AI Generated, Trusted Seller, Favorite, Offer, Chat, Report, Premium)
- Background graphics (gradients, mesh, floating icons, Ethiopian patterns)
- Product placeholder images (6 categories)

# 5. Generation guidance

- **Generate in one batch, in one style.** Do not hand-prompt each scene ad hoc — different prompt styles produce drift, and drift kills the effect.
- **Lock the style system first** (tokens + the three languages above), then produce Tier 1 and the photos, judge the result, and only then expand to Tier 3.
- Icon set: match **Lucide** style so custom icons (AI Assistant, Fayda Verification, Seller Trust, Community, Smart Search, Offers, Favorites, Reports) blend seamlessly.

# 6. Bottom line

~12 well-crafted, consistent images — 1 signature hero + ~8 Tier-1 + 3 trust photos — win far more than 40 varied ones. The few signatures belong at the top of the tracker; the garnish stays optional.

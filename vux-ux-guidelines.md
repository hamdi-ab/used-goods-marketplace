# 1. Purpose

The VinTech UX Guidelines define how users interact with the marketplace.

The goal is to create experiences that are:

- Intuitive
- Fast
- Trustworthy
- Inclusive
- Mobile-first
- Consistent

These guidelines ensure every interaction supports users in successfully buying and selling second-hand goods.

---

# 2. UX Vision

Our marketplace should feel like a trusted local community where buying and selling is simple, transparent, and safe.

Every interaction should reduce uncertainty and build confidence.

---

# 3. Core UX Principles

## Clarity Over Cleverness

Interfaces should be immediately understandable. Avoid hidden actions or unconventional patterns.

---

## Trust First

Every screen should answer:

- Who is selling?
- What is the condition?
- How much does it cost?
- Where is it located?
- Why should I trust this seller?

---

## Fewer Steps

Minimize the number of actions required to complete a task.

Examples:

- Create listing in one guided flow
- Contact seller in one tap
- Save favorite instantly

---

## Progressive Disclosure

Show advanced options only when needed.

Examples:

- Advanced filters hidden behind "More Filters"
- Optional fields collapsed by default

---

## Mobile-First

Design for thumb-friendly interaction and limited screen space.

# 6. Navigation Guidelines

Primary navigation should expose only the most important destinations.

Desktop

- Home
- Categories
- Favorites
- Sell
- Dashboard
- Profile

Mobile

Bottom Navigation

Maximum 5 items

Overflow actions belong in a menu.

# 7. Search & Discovery

Search should support:

- Keywords
- Categories
- Price Range
- Condition
- City
- Sort

Future

- Natural language search
- Saved searches
- Personalized recommendations

Results should update quickly and clearly indicate active filters.

---

# 8. Listing Creation Experience

Goal: Publish a listing in under three minutes.

Recommended flow:

1. Select category
2. Upload photos
3. Enter title
4. Add description
5. Choose condition
6. Set price
7. Select location
8. Review
9. Publish

AI suggestions should accelerate—not replace—user input.

---

# 9. Trust & Safety UX

Trust indicators should appear before contact actions.

Display:

- Seller verification
- Rating
- Review count
- Join date
- Active listings
- Item condition
- Report listing action

Report flows should be simple and require minimal effort.

---

# 10. Buyer Experience

Priorities

- Discover products quickly
- Understand product condition
- Evaluate seller trust
- Contact seller easily

Avoid unnecessary interruptions before the user reaches the listing.

---

# 11. Seller Experience

Provide:

- Simple listing management
- Listing performance summary
- Offer management
- Clear edit actions

Allow sellers to save drafts and continue later.

---

# 12. Forms & Validation

Guidelines

- Ask only for necessary information
- Use sensible defaults
- Validate after interaction
- Explain errors in plain language

Example

❌ "Validation Error"

✅ "Please enter a price greater than 0 ETB."

---

# 13. Feedback & System States

Every user action should have a visible response.

Examples

Loading

- Skeletons
- Progress indicators

Success

- Toast notification
- Updated UI

Failure

- Friendly explanation
- Retry action

---

# 14. Mobile UX

Touch Targets

Minimum 44 × 44 px

Thumb Reach

Primary actions should be placed within comfortable thumb zones.

Gestures

Support:

- Swipe image gallery
- Pull to refresh
- Scroll restoration

Avoid horizontal scrolling for core content.

---

# 15. Accessibility

Requirements

- WCAG AA contrast
- Keyboard navigation
- Screen reader labels
- Visible focus states
- Respect reduced-motion preferences

Content should never rely on color alone to convey meaning.

---

# 16. AI Interaction Guidelines

AI is an assistant, not a decision-maker.

Rules

- Clearly label AI-generated content
- Allow editing before publishing
- Explain confidence when appropriate
- Never auto-publish changes

Example

✨ Suggested Title

[Accept]

[Edit]

[Regenerate]

---

# 17. Ethiopian Localization

Currency

Display prices in ETB.

Location

Use:

- City
- Sub-city
- Neighborhood (optional)

Phone Numbers

Support Ethiopian formats.

Language Roadmap

Phase 1

- English

Future

- Amharic
- Afaan Oromo
- Tigrinya

Design layouts should accommodate longer translated text.

---

# 18. Content & Microcopy

Tone

- Friendly
- Direct
- Respectful

Examples

Instead of:

"Authentication Failed"

Use:

"Incorrect email or password."

Instead of:

"No Results"

Use:

"We couldn't find any items matching your search."

Button labels should describe actions clearly.

Examples

- Publish Listing
- Contact Seller
- Save Listing
- Make Offer

# 19. UX Metrics

Measure experience using:

- Listing completion rate
- Search success rate
- Time to first contact
- Favorite conversion rate
- Offer submission rate
- Listing publish time
- Bounce rate
- Error rate

Track these metrics to guide future improvements.

# Closing Statement

The VinTech UX Guidelines define the experience standards that every feature must follow. By prioritizing trust, simplicity, accessibility, and mobile-first design, the marketplace can provide a reliable and enjoyable experience for buyers and sellers across Ethiopia. These guidelines should evolve with user feedback while preserving the product's core principles and interaction patterns.
